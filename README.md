# Leetphus — LeetCode hints, not answers

> One must imagine Sisyphus happy.

在 leetcode.cn 的 Chrome 侧边栏里问 Claude。它看得到你当前的代码和运行/提交结果，但**没 AC 之前只回答你问的那一个问题，不剧透**；提交通过后，自动帮你看看代码还能不能更简洁。

## 功能

- **侧边栏聊天**：每次提问自动附带题目、当前代码、最近一次运行/提交结果和报错；力扣页面本身不加任何按钮
- **不剧透**：没 Accepted 之前，不会顺手指出你没问到的错误
- **AC 后自动检查**：提交通过时自动看一遍代码有没有多写、能不能更简洁；失败不打扰。侧边栏没开时在后台完成，图标上标个 1
- **自己查资料**：Claude 可以查你在这道题的提交记录、社区题解、题目详情，以及本地记录的每次运行/提交
- **记住偏好**：问答会记下来，纠正它一次（比如「以后别直接给完整代码」），之后的回答都会照做；偏好可以在侧边栏里直接查看和修改
- **按题分会话**：每道题可以有多段对话，随时切换；模型可选 Opus 5.5 / Opus 4.6 / Gemini 3.8 Flash (Low)

## 白板模式（练面试手撕）

面试常见的是一片空白的编辑器：节点类、测试数据、`if __name__ == "__main__":` 里的调用和 print 都要自己写，直接运行看输出，没有判题。白板模式模拟的就是这个。

- 在力扣题目页打开侧边栏，点顶部的「白板」：新标签页打开这道题的白板，左边是题面，右边是空白编辑器（只有行号和自动缩进，没有补全）
- `⌘'`（和力扣一样）、`⌘↵` 或「运行」：用本机 `python3` 跑整份代码，10 秒超时；代码自动存到 `board/<slug>.py`
- 侧边栏照样能问，附带的是白板里的代码和运行输出
- 直接打开 `http://127.0.0.1:8765/board` 是选题页：CodeTop 前 100（`codetop-top100.json`，自带题面）和写过的题

## 安装

1. Chrome 打开 `chrome://extensions`，打开右上角「开发者模式」
2. 点「加载已解压的扩展程序」，选本仓库的 `extension/` 目录
3. 已打开的 leetcode.cn 页面刷新一下

需要本机装有 [Claude Code](https://claude.com/claude-code)（聊天走 `claude -p`）或 [Antigravity CLI](https://antigravity.google)（`agy`，聊天走 `agy -p`），用你本机的登录额度，不需要额外 API key。

## 使用

启动本地服务：

```
python3 server.py
```

点工具栏上的插件图标或按 `Alt+Shift+L` 打开侧边栏，然后正常刷题。回车发送，Shift+回车换行。

本地服务同时会把当前状态写到文件，方便在 Claude Code 里直接读：

| 文件 | 内容 |
|---|---|
| `latest.md` | 题目、当前代码、最近一次运行/提交结果 |
| `latest.json` | 同上 + 完整的判题原始 JSON |
| `history/` | 每次运行/提交各存一份 |
| `profile.md` | 它记住的偏好 |
| `qa.jsonl` | 问答记录 |

## 隐私

- 插件只在 `leetcode.cn/problems/*` 生效，只和 `127.0.0.1:8765` 通信
- 力扣登录状态只交给本地服务、只放内存，用于替你查提交记录和题解
- 以上本地数据文件都在 `.gitignore` 里，不会被提交
